# 🛡️ NetScan1

### Advanced Web-Based TCP Port Scanner

NetScan1 is a web-based network security tool developed using **ASP.NET Web Forms and C#**. It allows security students, developers, and authorized security testers to scan specific TCP ports and analyze the services exposed by a target system.

The application provides real-time scan statistics, service identification, banner/version detection, risk classification, response latency, and downloadable PDF security reports.

> ⚠️ **For authorized security testing and educational purposes only. Scan systems and networks only when you have permission.**

---

## ✨ Features

- 🎯 Scan a specific hostname or IP address
- 🔢 Scan individually selected TCP ports
- ⚡ Concurrent TCP port scanning
- 🔍 Open / Closed / Timeout detection
- 🧩 Common service identification
- 🏷️ Service version and banner detection
- ⚠️ Basic port risk classification
- 📡 TCP response latency measurement
- 🌐 Hostname and IP resolution
- 📊 Real-time scanning statistics
- 🔎 Search and filter scan results
- 📄 Professional PDF security reports
- 🛑 Scan cancellation support
- 💻 Responsive dark cybersecurity interface
- 🗃️ No unnecessary CSV export
- 🔐 Designed for authorized security testing
